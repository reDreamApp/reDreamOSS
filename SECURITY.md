# Security

If you find a security problem in this code, please report it privately through GitHub: the repository's **Security** tab → **Report a vulnerability** (private vulnerability reporting). Do not open a public issue. Include what you found and how to reproduce it; we will confirm receipt and tell you what happens next.

Each reDreamOSS server is run by its own operator, not by this project. A problem with one particular server (its configuration, its data, its availability) goes to that server's operator: the app shows their contact under Settings → Contact.

Please do not test against servers or accounts that are not yours.
